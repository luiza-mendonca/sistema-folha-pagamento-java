# Sistema de Folha de Pagamento 💻

Desenvolvi esse projeto durante meus estudos de Java, com o objetivo de praticar e aprofundar meus conhecimentos em Programação Orientada a Objetos (POO).

A proposta foi criar um sistema de folha de pagamento que permite cadastrar diferentes tipos de colaboradores e calcular seus salários de acordo com as características de cada um.

## Funcionalidades

- Cadastro de colaboradores padrão, comissionados e de produção.
- Geração automática de matrícula para cada colaborador.
- Cálculo de salários, incluindo comissões e produtividade.
- Exibição dos dados individuais dos colaboradores.
- Resumo da folha de pagamento, com valor total e média salarial.
- Validação de informações durante o cadastro.

## Conceitos utilizados

O projeto foi desenvolvido em **Java**, utilizando:

- Classes, objetos e construtores
- Encapsulamento
- Herança e polimorfismo
- Sobrescrita de métodos
- Enum
- ArrayList
- Scanner

## Sobre o projeto

Esse foi um dos meus exercícios para entender melhor como as classes se relacionam e como aplicar herança e polimorfismo na prática.
